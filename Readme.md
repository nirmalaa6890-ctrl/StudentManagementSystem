🎓 Student Management System

📌 Project Overview

The Student Management System is a Python-based console application designed to manage student records efficiently.

It allows users to add, view, search, update, and delete student information. It also provides features like calculating student grades, sorting students based on marks, and calculating the overall class average.

This project is developed using Python concepts such as Object-Oriented Programming (OOP), File Handling, Exception Handling, and Data Structures.

🚀 Features

- Add Student: Add new student records with ID, name, age, course, and marks.
- Display Students: View all registered student details.
- Search by ID: Find student records using their unique ID.
- Update Student: Modify existing student information.
- Delete Student: Remove student records with confirmation.
- Search by Name: Search students using their names.
- Sort by Marks: Arrange students based on their average marks.
- Grade Calculation: Automatically calculate student grades.
- Class Average: Calculate the average marks of all students.
- Data Persistence: Store student records using file handling.
